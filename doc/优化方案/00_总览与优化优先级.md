## 项目独特价值

z-biz-tool-sys 定位为**跨平台轻量系统监控仪表盘**（对标 iStat Menus / Stats / htop 理念），在 z-biz-tool 家族中承担"系统层可观测性 + 系统维护操作"职责：

1. **实时资源监控**：CPU（总体 + 每核心）、内存（用量/压力）、磁盘（分区/读写）、网络（上下行/接口）— 后端 `sysinfo` 采集能力已就位
2. **进程管理**：进程列表（PID/名称/CPU/内存/线程）+ 结束进程 — 后端 `get_processes` / `kill_process` 已实现
3. **系统维护**：垃圾文件扫描与清理、大文件查找、启动项管理、DNS 刷新 — 后端 `cleanup.rs` 已实现
4. **趋势可视化**：Recharts 面积图展示最近 60 秒 CPU/内存曲线

技术栈：Tauri 2 (Rust) + React 19 + TypeScript 5 + Ant Design 6 + Recharts 2 + Vite 6 + sysinfo 0.30

## 四项核心原则（贯穿所有文档）

| # | 原则 | 当前状态 | 目标 |
|---|------|----------|------|
| 1 | **危险系统操作需二次确认** | ⚠ 进程 kill 有 Popconfirm，但操作对象为假数据 | 所有破坏性操作（kill/清理/禁用启动项/DNS 刷新）均需明确确认 + 真实数据 |
| 2 | **只读监控优先** | ✗ 前端监控数据 100% 为 mock，未调用后端 | 监控链路全量接通后端，采集默认只读、低开销 |
| 3 | **采集低开销** | ✗ 每次命令新建 System 实例，CPU 采样恒为 0 | 单例采集器 + 定时刷新 + 增量推送，自身 CPU < 2% |
| 4 | **Agent 不自动执行破坏性操作** | ✗ agent/ 为 SQL 死代码，无系统 Agent | 系统 Agent 仅生成建议/诊断，执行需用户逐条确认 |

## 立即行动项（P0）

以下 5 项为**必须立即修复**的安全/功能致命问题：

### P0-1 · 前端监控数据 100% 为 mock，从未调用后端

- **位置**：[App.tsx L112-113](../../src/App.tsx)（`mockSystemInfo` / `generateMockData`）、[L333-338](../../src/App.tsx)（`processData` 硬编码）
- **后果**：CPU/内存/磁盘/网络/进程全部显示假数据；后端 6 个监控命令（`get_system_info` / `get_cpu_usage` / `get_memory_info` / `get_disk_info` / `get_network_stats` / `get_processes`）从未被前端调用
- **修复**：建立 `useSystemMonitor` hook，定时 invoke 后端命令，替换全部 mock 数据源

### P0-2 · 假进程列表 + 真实 kill -9 = 误杀任意进程

- **位置**：[App.tsx L333-338](../../src/App.tsx)（硬编码 PID 1234/2345/3456/4567）→ [L275-282](../../src/App.tsx)（`handleKillProcess`）→ [lib.rs L298-320](../../src-tauri/src/lib.rs)（`kill -9`）
- **后果**：用户点击"结束 Google Chrome"实际执行 `kill -9 2345`，若该 PID 属于其他关键进程则造成系统损害
- **修复**：进程列表必须来自 `get_processes` 真实数据；kill 前校验 PID 存在性与归属

### P0-3 · flush_dns_cache 使用 sudo，GUI 应用内必挂起或失败

- **位置**：[lib.rs L323-355](../../src-tauri/src/lib.rs)（`Command::new("sudo")`）
- **后果**：无 TTY 环境下 sudo 等待密码输入 → 进程挂起；或报 "sudo: a terminal is required"
- **修复**：macOS 改用 `dscacheutil -flushcache` + `killall -HUP mDNSResponder`（无需 sudo）；Linux 改用 `resolvectl flush-caches`；或移除该功能改为提示用户手动执行

### P0-4 · CSP 完全禁用

- **位置**：[tauri.conf.json L23](../../src-tauri/tauri.conf.json)（`"csp": null`）
- **后果**：WebView 可加载任意远程脚本，配合 `shell:allow-execute` 构成完整攻击链
- **修复**：启用严格 CSP（`default-src 'self'; script-src 'self'; connect-src ipc: http://ipc.localhost`）

### P0-5 · 网络接口数据全错（Debug 打印当 IP、MAC 硬编码、收发字节互换）

- **位置**：[lib.rs L121-128](../../src-tauri/src/lib.rs)（`ip: format!("{:?}", data)` / `mac: "AA:BB:CC:DD:EE:FF"`）、[L215-216](../../src-tauri/src/lib.rs)（`bytes_received: total_transmitted()` / `bytes_sent: total_received()` 互换）
- **后果**：网络 Tab 显示 Rust 结构体 Debug 字符串而非 IP；MAC 全为假值；上下行流量颠倒
- **修复**：使用 `sysinfo::Networks` 正确 API 或 `pnet` / `mac_address` crate 获取真实接口信息

## 首要决策

1. **先通后优**：Phase 1 必须先把 mock 数据替换为真实后端数据，否则所有"监控"功能名不副实
2. **安全优先于功能**：P0-2（假 PID 真 kill）和 P0-3（sudo 挂起）在功能开发前必须修复
3. **采集单例化**：废弃"每命令新建 System"模式，改为 Tauri managed state 持有唯一采集器
4. **Agent 只建议不执行**：系统 Agent 可诊断"哪个进程占 CPU 高"，但 kill 操作必须用户手动确认
5. **共享库复用**：接入 `z-biz-tool-shared` 的 AppShell/ThemeContext/notifications，删除 `src/agent/` SQL 死代码
6. **测试跟随实现**：每个 Phase 的任务必须同步编写对应测试，夹具使用 mock 系统数据，不碰真实进程
