## 已确认缺陷（源码直接可证）

### FUNC-01 · 前端监控 100% mock，后端 6 命令从未被调用 — P0

[App.tsx L93-108](../../src/App.tsx) 定义 `mockSystemInfo`（硬编码 "Apple M3 Pro" / 18GB 等）；[L112-113](../../src/App.tsx) `useState(mockSystemInfo)` + `generateMockData(60)`；[L134-151](../../src/App.tsx) 每秒 `Math.random()` 更新趋势。全局搜索 `invoke` 仅 6 处，均为清理/kill/DNS 命令，**无 `get_system_info` / `get_cpu_usage` / `get_memory_info` / `get_disk_info` / `get_network_stats` / `get_processes`**。

### FUNC-02 · 假进程列表 + 真实 kill -9 — P0

[App.tsx L333-338](../../src/App.tsx) 硬编码 PID 1234/2345/3456/4567 → [L275-282](../../src/App.tsx) `invoke("kill_process", {pid})` → [lib.rs L298-320](../../src-tauri/src/lib.rs) 执行 `kill -9`。用户点击"结束 Google Chrome"实际 kill 真实 PID 2345（可能属于任意进程）。

### FUNC-03 · flush_dns_cache 依赖 sudo — P0

[lib.rs L326-327](../../src-tauri/src/lib.rs) `Command::new("sudo").args(["dscacheutil", "-flushcache"])`。GUI 无 TTY → sudo 挂起或失败。Linux 分支（[L337-338](../../src-tauri/src/lib.rs)）同样。

### FUNC-04 · 网络接口数据全错 — P0

[lib.rs L121-128](../../src-tauri/src/lib.rs)：`ip: format!("{:?}", data)`（Debug 打印非 IP）、`mac: "AA:BB:CC:DD:EE:FF"`（硬编码）、`speed: 1000`（硬编码）。[L215-216](../../src-tauri/src/lib.rs)：`bytes_received: total_transmitted()` / `bytes_sent: total_received()`（语义互换）。[L217-218](../../src-tauri/src/lib.rs)：packets 硬编码 0。

### FUNC-05 · 大文件扫描 "~" 不展开 — P1

[App.tsx L229](../../src/App.tsx) 传 `path: "~"` → [cleanup.rs L329-333](../../src-tauri/src/cleanup.rs) `PathBuf::from("~").exists()` = false → 返回空。前端 catch 后显示 mock（[L238-248](../../src/App.tsx)）。

### ARCH-01 · 每命令新建 System，CPU 采样恒 0 — P1

[lib.rs L148-149](../../src-tauri/src/lib.rs) `System::new()` + `refresh_cpu()`：sysinfo 需两次采样差值，首次无前值返回 0。同样问题：[L165](../../src-tauri/src/lib.rs)(memory)、[L184](../../src-tauri/src/lib.rs)(disk)、[L209](../../src-tauri/src/lib.rs)(network)、[L228](../../src-tauri/src/lib.rs)(processes)。

### ARCH-02 · App.tsx 902 行单文件，无状态管理 — P1

全部 7 Tab UI + 逻辑 + 类型 + mock 集中一个文件。README 宣称"Zustand"但仅死代码 [AgentManager.ts L1](../../src/agent/AgentManager.ts) 使用。

[AgentManager.ts L19](../../src/agent/AgentManager.ts) `name: 'SQL Agent'`；[types.ts L20-27](../../src/agent/types.ts) `AgentContext{connectionId, databaseType}`。App.tsx 无 import。~530 行无效代码。
