## F1 · 资源监控仪表盘

**当前**：概览 4 卡片（[App.tsx L386-458](../../src/App.tsx)）数据源为 `mockSystemInfo` + `Math.random()`（[L93-151](../../src/App.tsx)）。趋势图 60 点（[L461-500](../../src/App.tsx)）。

**目标**：

| 子项 | 规格 |
|------|------|
| CPU | 总使用率 + 每核心 mini bar（折叠式）+ 频率 |
| 内存 | 已用/可用/缓存/交换 + 压力等级（normal/warning/critical） |
| 磁盘 | 每分区使用率环 + Read/Write MB/s |
| 网络 | 每接口 ↑↓ 实时速率 + 累计 + 状态(up/down) |
| 温度(P2) | CPU/GPU 温度、风扇（macOS SMC / Linux hwmon） |

**交互改造**：刷新频率可调（1s/2s/5s/暂停，持久化）；卡片可折叠/排序；阈值可配置（默认 CPU 80%/内存 85%/磁盘 90%）；迷你菜单栏模式（P2）。

## F2 · 进程列表与操作

**当前**：4 条硬编码数据（[L333-338](../../src/App.tsx)），Popconfirm→`kill -9`（[L320-328](../../src/App.tsx)）。

**目标**：真实枚举（默认隐藏 kernel 线程）；搜索（名称/PID 实时过滤）；列头排序（CPU↓/内存↓/PID↑/名称）；详情面板（路径/启动时间/父进程）；安全 kill（SIGTERM→3s→SIGKILL + 系统进程禁止）；批量操作（多选+确认）；500+ 进程虚拟滚动。

**交互**：进程归属标识（用户/系统/其他）；CPU>50% 行高亮；右键菜单（结束/复制PID/在Finder显示）。

## F8 · Agent 辅助诊断（P2）

- 自然语言查询："哪个进程占 CPU 最高？" → 采集 → 排序结果
- 异常诊断："为什么这么卡？" → 分析 CPU/内存/磁盘/进程 → 诊断报告
- 操作建议：渲染为"待确认卡片"，用户点击才执行，**Agent 不自动执行**
- 安全边界：禁止直接调用 kill/cleanup/disable（见 [04 文档 S4](./04_数据安全与可靠性.md)）
