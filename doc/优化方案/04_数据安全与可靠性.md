## S1 · 危险操作分级与确认

| 级别 | 操作 | 确认方式 | 当前 |
|------|------|----------|------|
| L3 致命 | kill 系统进程（PID≤100 / 保护列表） | **禁止**，按钮灰显 | ✗ 无限制 |
| L2 高危 | kill 用户进程、清理 Risky、删除启动项 | Dialog + 输入名称验证 | ⚠ 仅 Popconfirm |
| L1 中危 | 清理 Safe/Moderate、DNS 刷新、禁用启动项 | Popconfirm | ⚠ 部分缺失 |
| L0 只读 | 查看监控、扫描、枚举 | 无需确认 | ✓ |

```rust
    pub async fn kill(pid: u32, grace_ms: u64) -> KillResult {

    }
}
```

前端流程：点击"结束" → `validate_kill(pid)` 获取真实进程名 → 按级别弹确认 → 执行。

### cleanup 加固

- ids 必须属于 `get_junk_paths()` 白名单
- 路径 `canonicalize` 解析符号链接，确认仍在预期目录内
- 黑名单拒绝：`/System`, `/usr`, `/bin`, `/etc`, `C:\Windows`, `~/.ssh`
- Risky 级别需一次性确认 token（防重放）
- 删除前记录 manifest（路径+大小），操作日志可追溯

### 启动项操作

- 所有操作前备份原始配置到 `app_data_dir/startup_backup/`
- `remove_startup_item` 为 L2 级别，需输入名称确认

## S2 · 采集不泄漏敏感信息

| 字段 | 风险 | 处理 |
|------|------|------|
| 进程名 | 低 | 原样展示 |
| 完整路径 | 中（暴露用户名） | 默认仅 basename；详情面板展示全路径 |
| 命令行参数 | **高**（`--password=xxx`） | 默认不采集；开启后对 `password|token|secret|key` 模式脱敏为 `***` |
| 环境变量 | **高** | 不采集、不展示 |

### 日志脱敏（规划新增 `src-tauri/src/log_sanitize.rs`）

- 路径用户名：`/Users/zifang/` → `/Users/<user>/`
- IP：`192.168.1.100` → `192.168.*.*`
- 敏感关键词后内容：`password=abc` → `password=***`
- 应用范围：所有 error/warn 日志、返回前端的 Err(String)、cleanup errors 字段

### 持久化最小化

进程快照、命令行参数**不持久化**。仅持久化：用户偏好（localStorage）、历史趋势（聚合数据）、告警记录、Agent 对话（脱敏后）。

## S3 · 只读监控优先

监控采集链路（metrics/processes/disks/networks）**永远只读**，不修改系统状态。

**DNS 刷新去 sudo 方案**：

| 平台 | 方案 | 备注 |
|------|------|------|
| macOS | `dscacheutil -flushcache`（macOS 12+ 无需 sudo） | 若需 `killall mDNSResponder` 则提示用户手动 |
| Linux | `resolvectl flush-caches`（用户级） | 无 systemd-resolved 时返回明确错误 |
| Windows | `ipconfig /flushdns`（已正确，无需管理员） | 保持现状 |

**绝不**在应用内调用 `sudo`。失败时返回可复制的手动命令。

## S4 · Agent 安全边界

**核心原则：Agent 只建议，不执行。**

| 能力 | Agent 可调用 | 需用户确认 | 禁止 |
|------|:---:|:---:|:---:|
| 读取 metrics/进程/磁盘/网络 | ✓ | | |
| 终止进程 / 清理 / 禁用启动项 / DNS | | ✓（走 S1 流程） | |
| 执行任意 shell / 修改系统配置 / 访问其他用户数据 | | | ✗ |

- Agent 建议必须匹配预定义操作模板，自由文本命令一律拒绝
- Agent 上下文不注入环境变量、SSH 密钥、Cookie 等敏感内容
- 建议渲染为"待确认卡片"，用户点击"执行"才触发正常安全流程

## S5 · Tauri 权限收敛

### capabilities 改造（规划）

```json
{
  "permissions": [
    "core:default", "core:event:default", "core:event:allow-listen", "core:event:allow-emit",
    "dialog:default", "dialog:allow-message", "dialog:allow-ask", "dialog:allow-confirm",
    "notification:default", "notification:allow-notify"
  ]
}
```

**移除**：`fs:default`、`fs:allow-read`、`shell:default`、`shell:allow-execute`。前端无需直接文件/shell 访问，全部走后端 command。

**插件精简**：移除 `tauri-plugin-shell`、`tauri-plugin-fs`；新增 `tauri-plugin-notification`。

### CSP 启用（规划）

```json
"csp": "default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; connect-src ipc: http://ipc.localhost; font-src 'self' data:"
```

Ant Design CSS-in-JS 需 `'unsafe-inline'`；Recharts inline SVG 需 `data:`。

## S6 · 可靠性设计

### 错误处理统一（规划新增 `src-tauri/src/error.rs`）

```rust
pub struct AppError { pub code: String, pub message: String, pub detail: Option<String> }
// code: "PERMISSION_DENIED" / "PID_NOT_FOUND" / "PATH_DENIED" 等
// detail 仅 debug 构建包含
```

### 采集器容错

| 故障 | 处理 |
|------|------|
| refresh 失败 | 返回上次缓存 + `stale: true` |
| 进程枚举部分失败 | 跳过失败项，不中断 |
| 磁盘不可达 | 标记 `available: false` |
| 前端未 listen | emit 静默忽略 |
| 采集循环 panic | catch_unwind + 重启 |

### 清理操作

- 清理前生成 manifest（JSON）
- 逐文件删除，失败记录 errors（已实现 [cleanup.rs L299-303](../../src-tauri/src/cleanup.rs)）
- 新增 CancellationToken 支持中断
- 文件删除不可逆，中断后已完成部分不回滚
