# 06 — 测试验收与风险清单

> **状态**：设计方案，未实现；基线 `7c7e8a2`；当前事实 = 静态代码证据，指标 = 拟定验收目标
>
> **重要声明**：当前项目**零测试覆盖**（无 Rust `#[test]`、无 TS `describe/it`、无 E2E 框架）。本文档所有测试用例均为**规划**，未执行、未通过。

---

## 测试策略总则

| 原则 | 说明 |
|------|------|
| **夹具使用 mock 系统数据** | 所有测试使用预构造的 MetricsSnapshot / ProcessInfo 夹具，**不碰真实进程、不执行真实 kill、不删除真实文件** |
| **未测不声称通过** | 任何功能在测试编写并绿色前，不得在文档/README 中宣称"已实现" |
| **后端单元测试不依赖 Tauri runtime** | 纯 Rust 逻辑（safety/cleanup/monitor delta）可 `cargo test` 独立运行 |
| **前端测试 mock IPC** | `@tauri-apps/api/core` 的 `invoke` / `listen` 通过 vitest mock 替换 |
| **E2E 仅在 CI 手动触发** | 涉及真实系统状态的 E2E 标记 `#[ignore]`，需显式 `--ignored` 运行 |

### 集成测试（IT）— 规划 10 项

| # | 范围 | 用例 | 验证点 |

| IT-01 | MonitorService | 启动后 1s 内 emit 首帧 metrics | 事件名 + payload 结构完整 |

| IT-06 | scan_junk_files | 扫描 tempdir 夹具返回正确 size/count | JunkReport 字段匹配 |
| IT-07 | cleanup_junk_files | 清理 tempdir 夹具后文件消失 + freed_bytes 正确 | CleanupResult 匹配 |
| IT-08 | find_large_files | tempdir 中创建 >threshold 文件 → 返回 | 路径 + 大小匹配 |
| IT-09 | get_startup_items | 返回 Vec（可为空），不 panic | 结构体字段完整 |

**夹具策略**：使用 `tempfile::TempDir` 构造文件系统夹具；进程相关测试使用 mock PID（如 99999999，确保不存在）。

### 性能测试（PERF）— 规划 6 项

| # | 指标 | 目标 | 测量方法 | 假设条件 |
|---|------|------|----------|----------|
| PERF-T01 | 采集器 CPU 占用 | < 2% | 运行 60s，取应用进程平均 CPU | macOS M3 Pro, 1s 间隔, 12 核 |
| PERF-T02 | 应用总 RSS | < 80MB | 运行 5min 后读取 RSS | 含 WebView + 200 进程缓存 |
| PERF-T03 | IPC 单帧延迟 | < 5ms | 前端 emit→receive 打点 × 100 取 P95 | MetricsSnapshot ~800B |
| PERF-T04 | 进程列表渲染 | < 100ms | 500 行数据渲染完成时间 | 虚拟滚动开启 |
| PERF-T05 | 冷启动到首帧 | < 2s | 进程启动→首条 metrics 事件到达 | 含 System 初始化 |
| PERF-T06 | 垃圾扫描耗时 | < 30s | scan_junk_files 返回时间 | 典型 macOS 用户目录 ~100 万文件 |

### 故障注入测试（FI）— 规划 4 项

| # | 故障 | 注入方式 | 预期行为 |
|---|------|----------|----------|
| FI-01 | sysinfo refresh 失败 | mock System trait 返回 Err | 使用上次缓存 + 标记 stale，不 panic |
| FI-02 | 前端未 listen 事件 | 不注册 listener，后端持续 emit | 后端不堆积、不 crash |

## 风险清单

| # | 风险 | 概率 | 影响 | 缓解措施 |
|---|------|------|------|----------|
| R-01 | sysinfo 0.33 API 破坏性变更导致编译失败 | 中 | 高 | 先在新分支升级 + 适配；保留 0.30 回退路径 |
| R-02 | macOS 温度采集需 IOKit 私有 API，App Store 审核拒绝 | 中 | 中 | 温度功能标记为"实验性"，非 Mac App Store 分发 |
| R-03 | Windows 进程线程数 API 兼容性（NtQueryInformationProcess） | 低 | 低 | 线程数列在 Windows 显示 "—"，不阻塞发布 |
| R-04 | 虚拟滚动与 Ant Design Table 排序/选择冲突 | 中 | 中 | 备选方案：react-window 自定义列表 |
| R-05 | 事件推送频率过高导致 WebView 卡顿 | 低 | 高 | 背压 Skip 策略 + 前端 requestAnimationFrame 节流 |
| R-06 | 垃圾清理误删用户重要文件 | 低 | **致命** | 白名单 + canonicalize + Risky 需输入确认 + 操作日志 |
| R-07 | Agent LLM 调用泄漏系统信息到外部 API | 中 | 高 | 默认本地模型；若用远程 API，上下文脱敏 + 用户明确授权 |

## 验收流程

```
开发完成 → 本地 cargo test + vitest 全绿
    ↓
推送分支 → CI 自动运行 UT + IT + Clippy + 构建
    ↓
Phase 结束 → 手动运行 E2E（#[ignore] 测试）+ 性能基准
    ↓
Code Review → 检查安全清单（SEC-V01~V10）
    ↓
合入 main → 打 tag → 四平台构建 → Release
```

**未通过处理**：任何验收指标未达标 → 阻塞合入 → 记录到 Issue → 修复后重新验收。
